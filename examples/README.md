# Ejemplos docentes

Este directorio conserva el material de referencia con sus atribuciones originales.
No forma parte del ejecutable ni del despliegue del Sprint 0. Las fuentes activas
están en src/ y sus diseños en doc/.

- BTLEAlumnos2021: recepción y análisis BLE originales.
- HolaMundoServicio2021: ejemplo de servicio Android.
- PeticionarioREST: ejemplo de cliente REST.
- EsqueletoWebAppEnPHPConSesion: ejemplo de web con sesiones.

Las rutas internas se conservan y los archivos están identificados como ejemplos.
No utilizar estas muestras como aplicaciones de entrega ni subirlas a Plesk.
